# Alura MIDI

Exercício de interface musical em HTML, CSS e JavaScript, com botões associados a arquivos de áudio.

## O que o projeto apresenta

- Teclas visuais e arquivos WAV.
- Associação de botões a seletores de áudio.
- Tratamento de foco e estilo ativo para Space e Enter.

## Tecnologias

HTML · CSS · JavaScript · Audio

## Executar localmente

Clone o repositório e abra `index.html` no navegador. Para servir os arquivos localmente, use um servidor estático, como Live Server. Não há etapa de build.
